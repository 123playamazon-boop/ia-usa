# IA USA — Importação dos EUA para o Brasil

Plataforma de catálogo de produtos importados dos EUA, com atendimento via WhatsApp.

- **index.html** — a loja (vitrine pública, mobile-first)
- **admin.html** — o back-office / BI (pedidos, rastreio, margem, declaração de importação)

Back-end: Supabase (banco, storage de fotos, funções do robô que garima best-sellers da Amazon, calcula custo-Brasil, traduz com IA e publica).
